NewsExplorer: Frontend

This project focuses on building the user interface for the News Explorer application. The main goal was to develop a responsive and interactive web app that connects to a REST API and supports user authentication. The application allows users to search for news articles, view them in a card-based layout, and manage saved articles within their personal profile.

Project Features
User authentication flow including sign up, sign in, and sign out using JWT tokens
Ability for users to search for news articles by keyword
Display of news articles in a structured card layout
Functionality to save and remove articles from a user’s profile
Fully responsive design for desktop, tablet, and mobile devices
Technologies Used
React
JavaScript (ES6+)
HTML5
CSS3
Semantic HTML
Flexbox and positioning
BEM methodology for file structure
Vite (for fast development and build tooling)
Development Setup

This project uses a React + Vite setup, which provides fast hot module replacement (HMR) and optimized builds. It also includes ESLint for maintaining code quality.
